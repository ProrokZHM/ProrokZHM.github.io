Политика конфиденциальности

Для версии приложения 4.0.2. Разработчик: Zhmakin Nikita. Контакт: Zhmakinikita@gmail.com.

Приложение выполняет финансовые расчёты и помогает планировать платежи. Регистрация и аккаунт не требуются.

Данные на устройстве

Суммы, ставки, сроки, названия расчётов и долгов, даты и названия напоминаний, отметки оплаты, настройки и последние использованные инструменты обрабатываются на устройстве для расчётов, сохранений, календаря и быстрого доступа. Приложение не отправляет эти сведения разработчику или на собственные серверы. Доступ к контактам, микрофону, местоположению и банковским аккаунтам не запрашивается.

Реклама и обновления

После успешного расчёта в финансовых инструментах, кроме «Инфляции», приложение может запрашивать рекламные баннеры для вкладок «Результат» и «График». В разделе «Ещё» баннер может запрашиваться при открытии раздела. Следующее объявление может загружаться заранее после расчёта, чтобы быстрее появиться при переходе между вкладками. В каталоге и на вкладках ввода параметров рекламных запросов нет. Реклама доставляется через Yandex Mobile Ads. Рекламный SDK может обрабатывать технические данные устройства, сетевые сведения и рекламный идентификатор для доставки, защиты и измерения рекламы. Приложение не передаёт рекламному SDK суммы, ставки, сроки, названия долгов, результаты расчётов и данные календаря. Персонализация, отслеживание местоположения и передача аналитики приложения в SDK отключены на уровне доступных настроек SDK. Сведения об обработке данных Яндексом: Политика Яндекса . При отсутствии сети или рекламы расчёты работают, а пустое место баннера скрыто. Для проверки обновлений приложение обращается к официальному SDK RuStore. SDK может обрабатывать технические данные устройства и сведения о версии приложения. По нажатию «Обновить» запускается официальный процесс RuStore; автоматическая установка без согласия пользователя не выполняется. Правила обработки данных RuStore: Политика RuStore .

Хранение и защита

Данные хранятся в закрытом каталоге приложения с ограничениями доступа Android. Дополнительное шифрование данных самим приложением не применяется. Автоматическое системное резервное копирование данных отключено. Сохранённые записи остаются до удаления пользователем, очистки данных или удаления приложения. Последний удалённый расчёт сохраняется для отмены удаления. Временные изображения результатов хранятся в кэше до его очистки приложением, системой или пользователем.

Экспорт и обмен

По действию пользователя приложение экспортирует резервную копию в выбранное через Android место, включая доступные пользователю облачные сервисы. Экспортируемый файл содержит данные приложения и не зашифрован приложением. При отправке карточки выбранное приложение получает изображение с данными расчёта. Правила хранения сторонних сервисов определяются их политиками. Разработчик не получает эти файлы автоматически.

Напоминания

Разрешение на уведомления служит для созданных пользователем напоминаний; доступ к точным будильникам — для времени их доставки; вибрация — для оповещения; события загрузки и изменения времени — для восстановления расписания. Разрешения можно отозвать в Android. Уведомления могут содержать название события и сумму; видимость на экране блокировки зависит от настроек устройства. Напоминания не выполняют платежи.

Внешние сервисы

Кнопки Telegram, YouTube и ВКонтакте открывают сервис во внешнем приложении или браузере. Финансовые данные не добавляются к этим ссылкам. Далее действуют правила соответствующего сервиса. Если пользователь пишет разработчику по электронной почте, разработчик получает адрес отправителя, текст и отправленные вложения и использует их для ответа и решения обращения. Переписка хранится на время решения обращения и необходимой последующей поддержки; пользователь может запросить её удаление по контактному адресу. Не присылайте пароли, банковские реквизиты или ненужные для обращения сведения.

Удаление данных

Отдельные расчёты и напоминания можно удалить в приложении. Для полного удаления локальных данных, включая отмену удаления и кэш, очистите данные приложения в Android или удалите приложение. Экспортированные копии и отправленные изображения удаляются отдельно в выбранных местах хранения и сервисах. Разработчик не имеет удалённого доступа к данным на устройстве.

Изменения политики

При изменении обработки данных публикуется обновлённая редакция с новой датой. Текст доступен в разделе «О приложении».
